# Support

## Troubleshooting

Start with the built-in diagnostic:

```sh
oasis doctor
```

For a deeper provider check, run `oasis doctor --test-provider`. For connectivity and TLS issues, run `oasis doctor --network`.

## Questions and feature ideas

Use [GitHub Discussions](https://github.com/FAHTHIZ/oasis/discussions) for usage questions, design proposals and general help.

## Bugs

Use the [bug report form](https://github.com/FAHTHIZ/oasis/issues/new?template=bug_report.yml) and include the OASIS version, operating system, steps to reproduce and the exact error message.

Before sharing logs, remove API keys, access tokens, private repository paths and other sensitive information.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).
