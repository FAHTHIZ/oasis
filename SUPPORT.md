# Getting help with OASIS

## Start here

1. Run `oasis doctor`. It checks Node, Git, your model provider, the sandbox and your config, and tells you the next step in plain words.
2. Read the [user guide](docs/USER_GUIDE.md). The [install guide](docs/INSTALL.md) has a troubleshooting section.
3. In the browser workspace, press Ctrl+/ (⌘/ on a Mac) or choose **Help** for every shortcut explained.

## Ask a question

Use [GitHub Discussions](https://github.com/FAHTHIZ/oasis/discussions) for questions, setup help, ideas and things you built with OASIS. Search first; someone may have asked already.

## Report a bug or suggest a feature

[Open an issue](https://github.com/FAHTHIZ/oasis/issues/new/choose) and pick the form that fits. For bugs, include:

- the output of `oasis --version` and `oasis doctor`
- your operating system and model provider
- the steps that cause the problem, and what you expected

Remove API keys, tokens and private code before you post.

## Report a security problem

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) to report it privately.
