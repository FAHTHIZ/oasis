Add one level of undo to the taskflow project. Every change made through the store (add, update, remove) remembers the task list as it was just before that change, saved in the same task file under a `previous` key, so undo also works across separate CLI runs. `store.undo()` restores that previous list, saves it, clears `previous` (so a second undo does nothing) and returns `true`, or returns `false` when there is nothing to undo. `taskflow undo` prints `Undid last change.` or `Nothing to undo.` Existing task files without `previous` must still load, and `version` stays 1.
