Write scripts/archive-logs.mjs, a Node script run as `node scripts/archive-logs.mjs --before YYYY-MM-DD [--dir logs]`. It moves every daily log file named app-YYYY-MM-DD.log in the directory (default logs) whose date is strictly before the given date into <dir>/archive/YYYY-MM/ (by the file's own month), leaves other files alone, and writes <dir>/archive/manifest.json as {"moved": [{"file", "to"}]} where "to" is the new path relative to <dir> with forward slashes; running it again appends to an existing manifest. It must exit with status 2 and change nothing when --before is missing or not a YYYY-MM-DD date. Then run it once on logs/ with --before 2026-11-05.
