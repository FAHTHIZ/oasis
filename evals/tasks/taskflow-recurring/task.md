Add repeating tasks to the taskflow project. A task can have `repeat` set to `daily`, `weekly` or `null` (the default), via `createTask`/`updateTask` and the CLI flag `--repeat daily|weekly`. When the store marks a repeating task as done, it also adds a new open task with the same title, priority, tags, notes and repeat, a new ID, and a due date one day (`daily`) or seven days (`weekly`) after the completed task's due date. If the completed task had no due date, count from the completion day. The new task emits `added` like any other. Completing a task that is already done, or a task without `repeat`, creates nothing. Invalid repeat values are rejected with `Unknown repeat: <value>`. Keep every existing test passing and add tests for the new behavior.
