# Third-party data in src/data

These snapshots are generated from open data sources by scripts in `scripts/`.

| File | Generated by | Source | License |
| --- | --- | --- | --- |
| `model-catalog.json` | `scripts/update-model-catalog.mjs` | [models.dev](https://models.dev) (`/api.json`) | MIT, Copyright (c) 2025 models.dev |
| `secret-rules.json` | `scripts/update-secret-rules.mjs` | [Gitleaks](https://github.com/gitleaks/gitleaks) `config/gitleaks.toml`, regexes translated from Go RE2 to ECMAScript | MIT, Copyright (c) 2019 Zachary Rice |
| `popular-packages.json` (npm) | `scripts/update-popular-packages.mjs` | [npm-high-impact](https://github.com/wooorm/npm-high-impact) | MIT, Copyright (c) Titus Wormer |
| `popular-packages.json` (PyPI) | `scripts/update-popular-packages.mjs` | [top-pypi-packages](https://github.com/hugovk/top-pypi-packages), from the public [ClickHouse PyPI dataset](https://clickpy.clickhouse.com/); package names only | No license declared; package names and rankings are factual data |
| `popular-packages.json` (crates) | `scripts/update-popular-packages.mjs` | [crates.io API](https://crates.io/data-access), sorted by downloads; package names only | crates.io data access policy |
