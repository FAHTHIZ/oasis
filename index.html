YOUR CODING PARTNER

Build with Oasis.

Describe the change in plain English. Oasis can inspect your workspace, edit files, run checks, and ask before consequential actions.

Model provider

Connect runtime first

Choose a preset to fill in the endpoint, then confirm the exact model ID and test the connection. OmniRoute uses a local gateway on port 20128 and model auto; run oasis setup to install/start it or use this form when it is already running. Some OmniRoute setups require the local endpoint key shown in its dashboard. OpenRouter requires a model ID from its catalog; Ollama requires a running local server and an installed model. Provider credentials are accepted only from this same device over localhost and are saved to its local Oasis configuration. If you connect from a second device over the private-Wi-Fi bridge, configure the provider in the host terminal instead—this HTTP connection is not encrypted.

Start oasis web in the terminal for the project you want to work on, then paste its one-time connection token. The token is held in this browser tab's session storage, not in workspace notes.

Runtime not connected
Connect a runtime, then tell Oasis what you want to build.

Approval required

Oasis has a question

Commands, package installs, file deletion, and plugin installation wait for your approval. This runs code as your operating-system user; it is not an OS sandbox. Do not expose this HTTP server to the public Internet.
Terminal · command runnerReady when runtime is connected
Oasis terminal ready. Commands run in the selected workspace, without shell expansion. Review each approval request before allowing execution.

This is an approval-gated command runner, not a full interactive PTY yet. Use one executable and JSON arguments (for example, npm with ["test"]); shell chaining and interactive programs are not available here.

GitHub · repositories and workspacesNot checked

Connect through GitHub CLI on the computer running Oasis. This avoids putting a GitHub token in the browser.

One-time setup: install GitHub CLI (gh) on the computer, run gh auth login in its terminal, then check the connection here. Choosing a repository downloads it into .oasis/workspaces/ and switches the agent and command runner into that repo. Oasis does not execute cloned project scripts until you approve a command.

See the latest agent and terminal runs, including tasks interrupted by a runtime restart. This is durable local history for the connected Oasis host, not hosted cloud compute yet.
