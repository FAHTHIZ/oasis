# Code of Conduct

OASIS is an open-source project. Participation in its issues, discussions, reviews and other project spaces is expected to be respectful, constructive and focused on improving the software.

## Expected behaviour

- Be considerate and respectful when communicating with others.
- Critique ideas and code, not people.
- Provide actionable feedback and explain technical disagreements in good faith.
- Respect different levels of experience, backgrounds and communication styles.
- Keep discussions relevant to the project and its users.

## Unacceptable behaviour

- Harassment, threats, intimidation or personal attacks.
- Discriminatory or demeaning language directed at an individual or group.
- Publishing private information without permission.
- Deliberate disruption, impersonation or repeated bad-faith conduct.
- Unwelcome sexual attention or other conduct that makes project spaces unsafe.

## Maintainer response

Project maintainers may edit or remove content, close discussions, or restrict participation when behaviour violates this policy. Decisions should be proportionate to the behaviour and focused on keeping project spaces constructive.

To report a conduct concern, contact the repository maintainer privately through GitHub rather than raising it in a public issue or discussion. Include relevant links and context. Please do not publish another person's private information as evidence.

## Scope

This policy applies to project spaces, including GitHub issues, discussions, pull requests, code reviews and other channels operated for OASIS.

This document is informed by the principles of the [Contributor Covenant](https://www.contributor-covenant.org/).
