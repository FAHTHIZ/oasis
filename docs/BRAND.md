# OASIS brand guide

**Primary name:** OASIS  
**Primary tagline:** Code. Automate. Flourish.

OASIS is an open-source coding agent and local-first developer workspace. The portal mark is an arch with a fine inner contour and horizontal strata that taper inward as they descend. Preserve that silhouette; do not replace it with a generic ring, orb, lens, or unrelated geometric symbol.

## Color system

| Token | Hex | Use |
|---|---|---|
| Portal lime | `#7CFF5E` | Primary action, focus, key highlights |
| Growth green | `#32E07A` | Secondary accents, gradients, active states |
| Signal green | `#0ED168` | Deep gradient endpoint, success accents |
| Night | `#0B0F0C` | Main canvas and icon background |
| Graphite | `#1A1F1B` | Panels, elevated surfaces |
| Mist | `#E6F5EA` | Primary text and wordmark |

Use the three greens as a restrained portal gradient, not as three competing accent colors. Maintain readable contrast for text and controls. Avoid large neon-green text areas.

## Coding workspace palette

The coding workspace uses a flat interface palette. These interface colors do not recolor the portal mark or app-icon artwork.

| Token | Hex | Use |
|---|---|---|
| Workspace background | `#0B100C` | Main canvas |
| Sidebar | `#0D130E` | Navigation surface |
| Panel | `#101811` | Cards and workspace panels |
| Border | `#1C271F` | Quiet panel outlines |
| Strong border | `#2B3B30` | Emphasized outlines |
| Primary text | `#E8EFE9` | Main interface text |
| Muted text | `#9BAA9F` | Secondary copy; maintain at least 4.5:1 contrast |
| Action lime | `#9BFF55` | Send, New chat, and approval actions only |
| Risk / removed | `#FF8A8A` | Explicit risk labels and removed diff lines |
| Added diff | `#9BFF55` | Added diff lines |

Use Inter for interface text and JetBrains Mono for code. Keep surfaces flat, use 1px quiet borders and avoid gradient washes on cards. The original portal mark retains its existing brand artwork colors.

## Logo and wordmark

- The standalone portal mark is the default sidebar, favicon-adjacent, and small-space mark.
- The app icon uses the same mark on a rounded Night square.
- The wordmark is **OASIS**. Use OASIS consistently as the public product name; do not add secondary product-name suffixes.
- The primary tagline is **CODE. AUTOMATE. FLOURISH.** Use it once per placement.
- Keep clear space around the mark and do not stretch, rotate, or redraw its strata.

## Product interface

Use Night as the base, Graphite for panels, Mist for text, and Portal lime for the main action. Use Growth green for secondary states and Signal green for subtle status/success accents. Prefer quiet borders, soft green light, crisp spacing, and restrained glow over large gradients or neon outlines.

The coding workspace should remain the primary experience. Keep the conversation, approval prompt, model selection, and terminal controls clear and reachable. Preserve the local-first and permission boundaries in all setup and action copy.

## Motion

Motion should feel like the portal activating: short, calm fades and a restrained glow pulse. Respect `prefers-reduced-motion`; motion must never be required to understand status or progress.
