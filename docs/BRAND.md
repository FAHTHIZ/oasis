# OASIS brand

**Primary tagline:** Code. Automate. Flourish.

OASIS is an open-source AI coding agent and local-first developer workspace. Its mark is the selected lime arch with an inner contour and horizontal strata that taper inward and down. Keep the silhouette consistent: no generic ring, orb, camera lens, or “OSS” lockup.

## Assets

- `assets/oasis-icon.svg` — app icon and favicon.
- `assets/oasis-mark.svg` — transparent standalone mark.
- `assets/oasis-logo.svg` — horizontal logo lockup.
- `assets/oasis-readme-banner.svg` — README / social banner.
