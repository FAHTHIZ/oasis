# OASIS 1.0.0

**Status:** prepared notes; the release has not been published yet (checked November 4, 2026)  
**Planned tag:** `v1.0.0`, to be created by the desktop workflow from a verified `main` commit (commit `ac6858b` was the original candidate)  
**Channel:** stable  
**Downloads:** Windows x64 `.exe`, macOS arm64 `.dmg`, Linux x86_64 `.AppImage` and `.deb`, plus `SHA256SUMS`

OASIS 1.0 is the first stable release of the open-source, bring-your-own-model coding agent: one runtime behind the CLI, the local browser workspace, the desktop app, the VS Code integration, the SDK and the GitHub Action.

## Highlights

- **Works with any model.** Hosted providers (OpenAI-compatible, Anthropic, Gemini, DeepSeek, OpenRouter and others) and local servers (Ollama, llama.cpp, LM Studio, vLLM). Context windows are detected from the provider's `/models` listing or the local server.
- **Built for small and local models.** A compact system prompt for windows of 16K or less. Recovery of text, fenced, JSON Lines and XML-style tool calls. Nudges when a model describes instead of acting, announces a step and stops, gives up after one error, refuses an ordinary task, or claims a change it never made. Harness-run verification (diff plus project tests or a syntax check) when a small model forgets to check its work. A safe code-block fallback for new files. Every one of these came from live runs with Qwen2.5-Coder 1.5B and 3B on llama.cpp; see [Benchmarks](../BENCHMARKS.md).
- **Guardrails for the problems people report with other coding agents.** A post-edit verification gate, fix-thrash detection, weakened-test detection, plan mode enforcement, git safety snapshots, refusal of unrequested commits and pushes, history repair on cancel, honest completion reports, and signal-safe headless runs. The README's "Why OASIS" table maps each complaint to its guardrail.
- **Full agent toolkit.** Subagents and task coordination, MCP, hooks, Agent Skills, plugins, sessions with compaction, checkpoints and rewind, memory, worktrees, code review, diagnostics/LSP, background commands, web fetch and search, and a 33-task regression evaluator with Claude Code comparison mode.

The full list is in the [changelog](../../CHANGELOG.md).

## How 1.0 was verified

Every gate in the [project plan](../PROJECT_PLAN.md#6-10-release-gates-and-decisions) was checked on one commit: Quality Checks (Node 22/24/26; Windows, macOS and Linux runtime and security matrix; clean environment; native PTY; browser E2E with axe accessibility scans), installer checks on Windows, macOS and Ubuntu, desktop packaging for all three platforms, and public-site validation. The publish job requires those same-commit results again before it creates the tag and release, and refuses if `main` has moved.

## Known limits

- **Installers are not code-signed.** Windows SmartScreen and macOS Gatekeeper will warn on first launch. Verify downloads with `SHA256SUMS` ([how](../INSTALL.md)). Checksums detect corruption and tampering in transit; they are not a publisher signature.
- **Clean-machine journeys are CI-only.** Install and packaging are tested on fresh GitHub-hosted runners. First launch, update and uninstall were not tested by hand on physical machines for this release.
- Approved commands run with your OS user's permissions. The optional Linux/macOS sandbox is off by default and does not isolate file reads; there is no native Windows sandbox.
- Desktop auto-update is not configured.
- Android runs through Termux; there is no native APK.
- Browser Projects/Tasks/Notes data is not fully synchronized with CLI state.
- A runtime restart does not bring back live worker processes, PTY sessions or pending approvals.
- The 33-task evaluator is a regression suite, not a broad coding benchmark. Small local models (1.5B to 3B) still fail many tasks on code correctness; the harness surfaces those failures but cannot fix them.

## Upgrading from 0.4.0

Re-run the installer from the [install guide](../INSTALL.md); it resolves `v1.0.0`. Settings, sessions and memory in your OASIS config directory are kept.
