# OASIS 1.1.0

**Status:** published automatically by the desktop workflow when this version reached `main` and passed every same-commit gate.
**Tag:** [`v1.1.0`](https://github.com/FAHTHIZ/oasis/releases/tag/v1.1.0)  
**Channel:** stable  
**Downloads:**
- **Always included:** Windows x64 `.exe`, macOS Apple silicon `.dmg`, Linux x86_64 `.AppImage` and `.deb`, plus `SHA256SUMS`.
- **New optional builds:** macOS Intel `.dmg`, Linux ARM64 `.AppImage`/`.deb` and Windows ARM64 `.exe`, each included when its CI build succeeds.

OASIS 1.1 turns the desktop app into one download that keeps itself current and sets itself up for the computer it runs on.

## Highlights

- **Update notifications and verified installs.** The desktop app checks for a new stable release at launch and every six hours. It shows a system notification and a workspace banner, and offers **Install and restart**. The installer comes only from the GitHub release and must match the release `SHA256SUMS` before it runs.
  - **Windows:** reinstalls silently and reopens.
  - **Linux AppImage:** replaced in place, then relaunched.
  - **macOS and `.deb`:** the file opens in the system installer.
  - **CLI and `oasis web`:** the same notice, pointing to `oasis update`.
  - **Options:** **Later**, **Skip this version**, `OASIS_NO_UPDATE_CHECK=1` and `OASIS_UPDATE_CHANNEL=beta`.
- **Setup that fits your hardware.** `oasis setup --auto` and the first-run screen detect OS, CPU, memory and GPU (NVIDIA, Apple Silicon), plus any running Ollama, LM Studio, llama.cpp, Jan, vLLM or OmniRoute server. They recommend the best route: a running model that fits, an Ollama model sized to your memory, or a hosted model. A route is saved only after a live test request.
- **Phones and tablets.** `oasis web --host 0.0.0.0` prints real network links and a QR code to scan. The workspace installs to Android and iOS home screens with proper icons. See [MOBILE.md](../MOBILE.md).
- **Releases ship themselves.** A version bump on `main` with curated notes and passing gates publishes the release; nobody has to start it by hand. The download page detects your OS and CPU type and links its button straight to the right file.
- **Also in this release:**
  - Satisfying, rate-limited sound cues (`/sounds`).
  - Idle-time context compaction.
  - Fairer evaluation tasks, and $0 cost reporting for local models.

The full list is in the [changelog](../../CHANGELOG.md).

## How 1.1 was verified

The publish job is the same one that published 1.0. Before it creates the tag, it requires Quality Checks, installer checks and public-site validation to pass on this exact commit. It also checks that `main` has not moved and that the tag does not exist yet. The new update, hardware, QR and phone-link code has unit and end-to-end tests. Those include a tampered download that must be refused and the QR encoder checked bit for bit against an independent library.

## Known limits

- **Installers are not code-signed.** Windows SmartScreen and macOS Gatekeeper warn on first launch. Unsigned macOS apps cannot replace themselves, so macOS updates open the disk image for you to drag into Applications.
- **Clean-machine journeys are CI-only.** Install, packaging and the update logic are tested on GitHub-hosted runners and with simulated installers. First launch and a real update were not tested by hand on physical machines.
- **Updating from 1.0.0 is manual, once.** 1.0.0 has no update checker. Install 1.1.0 by hand; from then on, updates are offered automatically.
- **No App Store or Play Store app.** Phones use the browser workspace on a computer, a chat bot, or Termux on Android.
- Approved commands run with your OS user's permissions, and the optional sandbox is off by default.

## Upgrading from 1.0.0

Download the installer for your system from the [release page](https://github.com/FAHTHIZ/oasis/releases/tag/v1.1.0), or run `oasis update` for the CLI. Settings, sessions, memory and keys are kept.
