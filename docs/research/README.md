# Research and proposals

Research done on 2026-11-15 for the next stage of OASIS: a general-purpose
agent system built on the existing runtime. These documents are proposals
for review. They do not describe shipped behaviour unless they name an
existing file; the user-facing docs in [docs/](../README.md) describe what
OASIS does today.

| [OSS-ECOSYSTEM.md](OSS-ECOSYSTEM.md) | Comparison of agent frameworks, inference servers, memory stores, durable execution, protocols, training tools, sandboxes and open-weight models, with adopt / adapt / replace / build / reject verdicts |

| [MODEL-STRATEGY.md](MODEL-STRATEGY.md) | Using existing models, fine-tuning them, or building an original model, and when each is justified |
| [DEPENDENCIES-AND-LICENSING.md](DEPENDENCIES-AND-LICENSING.md) | Current licence state, rules for new dependencies, candidates, rejected projects, model-weight licences, attribution |
