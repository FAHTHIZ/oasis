## Architecture map (from the implementation)

- **Entry points** (`cli.mjs`, `headless.mjs`, `sdk.mjs`, `web.mjs`, `ide.mjs`, `acp.mjs`, `github-action.mjs`, gateways) all call one runtime: `createSession` and `runAgentTurn` in `agent.mjs`.
- **Agent loop** (`agent.mjs`, 6.4k lines): provider request and streaming for three protocols (OpenAI Chat Completions, Responses, Anthropic Messages, with Bedrock/Vertex/Foundry variants), retry and fallback chain (`fallback-chain.mjs`), steering, compaction (`context.mjs` plus mid-turn compaction), effort and thinking budgets, verification gate and completion heuristics, budget notices, subagent effort.
- **Tools** (`tools.mjs`, `power-tools.mjs`, `power-tool-definitions.mjs`): file tools with workspace confinement, `run_command` (argv, `shell:false`) and opt-in `run_shell` classified by `shell-risk.mjs`, permission modes and rules (`permissions.mjs`), tool-call repair for text-only and malformed calls (`tool-call-repair.mjs`), edit matching under drift (`edit-match.mjs`), placeholder and test-tamper guards.
- **Memory and context**: instruction files and other-agent rules (`memory.mjs`), auto-memory with BM25 recall, freshness and approval-gated writes (`auto-memory.mjs`), PageRank repo map (`repo-map.mjs`) injected per turn, read de-duplication (`read-dedup.mjs`), compaction with must-preserve items (`context.mjs`).
- **Coordination**: subagents (`subagents.mjs`), tasks (`agent-tasks.mjs`, `shared-tasks.mjs`), background sessions, worktrees, monitors, workflows in a QuickJS sandbox.
- **Economics**: pricing table (`pricing.mjs`), `maxBudgetUsd`, auxiliary usage charging, easy/strong routing (`model-routing.mjs`, off by default, deterministic and conservative).

## Strengths worth preserving

1. A large, green, fast-enough regression suite and a model-free harness benchmark with honest held-out sets.
2. Real enforcement layers rather than settings-only features: argv execution by default, risk classification, re-checks after hook rewrites, fail-closed sandbox requests, credential filtering for child processes (each covered by tests listed in `SECURITY_RELIABILITY_AUDIT.md`).
3. Strong mid-tier-model support: text tool-call recovery for many native formats, edit-drift tolerance, truncation recovery, local-server context detection.
4. Documentation that already separates measured results from design-only claims.

## Weaknesses that matter most

| Priority | Problem | Evidence | Plan |
|---|---|---|---|
| Critical | Token cost per task. Live runs used 34–71 times Aider's tokens on the same passed tasks. | `docs/research/LIVE_COMPARISON_2026-11-05b.md` | Build a deterministic token benchmark that drives the real loop with a scripted provider, profile system prompt / tool schemas / history / tool results, and reduce resent content without cutting verification. Measure every change. |
| Critical | No measurement of the token track. | `docs/BENCHMARKS.md` lists it as design-only. | Same benchmark, committed with a baseline result and a fast check mode. |
| High | Security enforcement must be proven by attacks, not by settings names: path confinement (symlinks, TOCTOU), shell-risk bypasses, local server Host/Origin and token checks, untrusted-output handling, secret redaction in every persisted artifact. | Prior audit covers many items; no adversarial sweep at this revision. | Attack tests first, minimal fixes, audit doc updated. |
| High | Agent-loop reliability under failure: no-progress loops, budget enforcement including subagents, cancellation, resume after a crash mid-tool-call for each protocol, malformed streams, fallback restoration. | Large, dense `agent.mjs`; behaviors spread across many helpers. | Scripted-provider failure tests; fix confirmed defects. |
| Medium | Modularity of `agent.mjs`, `cli.mjs`, `slash.mjs`, `tools.mjs`, `web.mjs`. | `src/README.md` | Extract only along tested boundaries when a fix needs it; no line-count-driven moves. |
| Medium | Live same-model comparisons are tiny (3 tasks, 1 trial). | `docs/BENCHMARKS.md` | Needs provider keys; blocked in this environment. Runner exists (`scripts/bench-live.mjs`). |
| Optional | Semantic (embedding) memory retrieval. | BM25 recall already works; no evidence of retrieval misses yet. | Only with a recall benchmark that shows a gap. |
