06 / SECURITY & TRUST

Power needs
clear boundaries.

OASIS can read and modify project files, run commands and send context to configured providers or external services. Treat it as software operating with the permissions of the process running it.

  • Approval prompts do not replace operating-system isolation.
  • Optional sandbox backends vary by platform and must be reported as unavailable when not active.
  • MCP servers, hooks, plugins and imported extensions can run third-party code.
  • Review diffs, keep backups, and check the data-handling terms of every provider you configure.
